Tecnologia & Legado

Conexão em Tempo Real

Utilizando a arquitetura moderna da Web com JavaScript assíncrono (Fetch API), conectamos nossa interface nostálgica aos servidores globais da PokéAPI.

Galeria de Personagens da API

Cards gerados 100% dinamicamente via JavaScript com consumo da PokéAPI

Especificações da Aplicação Front-End

  • Linguagens utilizadas: HTML5 semântico, CSS3 moderno (Flexbox, Grid e Variáveis CSS) e Vanilla JavaScript (ES6+).
  • Consumo de API: Requisições via fetch() assíncrono com tratamento de erros (try/catch).
  • Manipulação do DOM: Criação dos Cards via document.createElement() e appendChild().
  • Responsividade: Interface adaptável para celulares, tablets e computadores.
